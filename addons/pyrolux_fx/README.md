# PYROLUX Lite - Fire & Explosion VFX for Godot 4

Want more effects? PYROLUX Full: https://gennai.itch.io/pyrolux-fire-explosion-vfx?utm_source=godot_store&utm_medium=readme&utm_campaign=pyrolux_lite

A free sample of PYROLUX: a procedural campfire (`PyroluxFire3D`) and a ground explosion
(`PyroluxExplosion3D`) for Godot 4.4+. Works on Forward+, Mobile and Compatibility (Web).
No textures; everything is generated by shaders.

## Install

Installing from the Godot Asset Store adds two folders to your project:

- `addons/pyrolux_fx/` - the effects (nodes, shaders, presets, palette)
- `pyrolux_lite_demo/` - a small demo scene. You can delete it when you no longer need it.

Open `pyrolux_lite_demo/lite_demo.tscn` and press F6 (Run Current Scene).
Space or the on-screen button: explosion, E: fire on / off, H: help. The button in the
bottom right corner opens the Full version's page (only when clicked).

To use the effects, drag a preset from `addons/pyrolux_fx/presets/3d` into a scene, or add
`PyroluxFire3D` / `PyroluxExplosion3D` from the Add Node dialog (search "Pyrolux").

## Use

```gdscript
$Campfire.ignite()
$Campfire.extinguish()
Pyrolux.spawn(self, "explosion_grenade", hit.position)
$Explosion.explode_at(point)
```

Presets: `fire_campfire`, `fire_torch`, `explosion_grenade`. The fire's `shape`, `size`,
`flame_height`, colours (`palette`) and the explosion's `radius` and parts are all editable.

## Full version

PYROLUX Full adds 10 3D effect types and 5 2D types (with pixel-art mode):

- bonfires, walls and rings of fire, coloured fire
- mushroom clouds, air bursts, napalm
- smoke columns, sparks, embers and ash
- lava pools and rivers, flamethrowers and thrusters, meteors, scorch marks
- `PyroluxBurn3D`, which sets any mesh on fire and lets it char or burn away
- 49 presets, 6 palettes, a browser demo and a click-to-explode playground

The Full addon uses the same folder (`addons/pyrolux_fx/`) and the same node names, so
upgrading is copying it over this one.

Get it on itch.io: https://gennai.itch.io/pyrolux-fire-explosion-vfx?utm_source=godot_store&utm_medium=readme&utm_campaign=pyrolux_lite
